# 📖 About

DocConnect is a full-stack MERN application developed to simplify healthcare management by connecting patients with doctors through an intuitive digital platform. The application enables users to find doctors, schedule appointments, manage bookings, and experience secure healthcare services with a modern and responsive interface.

---

# ✨ Features

- 🩺 Browse Experienced Doctors
- 📅 Online Appointment Booking
- 👨‍⚕️ Doctor Profiles & Specializations
- 👤 Secure User Authentication
- 📋 Appointment Management
- 📱 Fully Responsive Design

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/najatul6/DocConnect-Client.git
```

Move into the project

```bash
cd DocConnect-Client
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
